# EX.No.-2.2 CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING


## AIM: 

To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## procedure:
1. Create the Base Sketch: Open Fusion 360, select the XY plane, create a new sketch, and draw a horizontal slot with an overall dimension of 92 mm and end radius R18 mm.

2. Draw the Base Holes: Draw two circles at both ends of the base, apply a diameter of Ø16 mm, and maintain a centre-to-centre dimension of 56 mm between them.

3. Apply Dimensions and Trim: Use the Dimension tool to set the base length, hole diameter, and centre distance, then use the Trim tool to remove unwanted sketch lines.

4. Extrude the Base: Finish the sketch and use the Extrude command to give the base plate a thickness of 8 mm, creating the bottom supporting structure.

5. Create the Vertical Support: Select the top face of the base, start a new sketch, draw the rectangular supporting section, apply the required dimensions, and use Trim to remove extra lines.

6. Extrude the Support: Select the completed rectangular sketch and use Extrude to create the vertical supporting wall, maintaining the overall object height of 70.24 mm.

7. Create the Upper Arm: Select the appropriate support face, start a new sketch, draw the horizontal connecting arm, apply the required dimensions, and use Trim to clean the unwanted sketch portions.

8. Create the Top Circular Boss: On the upper arm, draw two concentric circles with an outer diameter of Ø30 mm and an inner diameter of Ø20 mm, then trim unnecessary sketch geometry.

9. Create the Slanting Support: Draw the inclined supporting section using the required 83 mm side-view length, apply the necessary dimensions, and use Trim to remove unwanted lines before extruding.

10. Complete the Final Model: Check all dimensions, R18 radius, Ø16, Ø20 and Ø30 diameters, apply the required Extrude operations, and use Fillet if needed to finish the model.
